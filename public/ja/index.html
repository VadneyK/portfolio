02道具 Agent tools and libraries

local-coder

Claude CLI の上で動く、自律型コーディングエージェントの実行基盤です。ボードのワーカーが GitHub の課題を引き受けて PR まで仕上げ、キューランナーが夜間の無人実行を担当し、監査ループが自分で課題を登録して直します。メモリ監視はマシンに負荷がかかるとワーカーを止め、計測でタスクごとの時間、成功率、モデルの使用量を追います。コミットは新しいブランチにだけ行い、強制プッシュはせず、秘密情報には触れません。

cloud-coder

YAML でタスクを並べ、寝ている間に Claude Code で実行します。監査と修正のループ付きで、コードベースを監査して採点し、足りない点ごとに修正タスクを作って実行し、目標の点数まで再監査を繰り返します。本番に向けた強化の期間に作り、あるプラットフォームの準備度監査を10点中5.8から8.8に引き上げました。

fable-lenses

高価なモデルをコードベースのどこに向けるべきかを、安く決定的に順位づけするツールです。各ファイルを、影響 (git の変更頻度) と機会 (実際の循環的複雑度と入れ子の深さ) の掛け算で採点し、リポジトリ内で五分位に分けます。これでモデルは全部を読むのではなく、効果の大きい所から始められます。

quiz-difficulty

選択式の問題に、候補の答えを輪のように並べて、やさしい、ふつう、むずかしいの選択肢を作る npm パッケージです。結果は決定的で、「むずかしい」が「ふつう」よりやさしくなることは決してありません。多くの難易度設定で気づかれずに起きている失敗です。

03ものづくり Hardware and 3D printing

makerspace-3d

メイカースペースの Bambu Lab X1 Carbon (AMS 付き) を使うための知識をまとめた Claude Code プラグインです。プリンターの設定と苦労して得たスライスのルール、設計用のスキル、レンダリング、寸法、造形しやすさを確かめる CAD サーバー、そして Bambu Studio のコマンドラインで多色のプロジェクトを組み立てるスライス用ツールが入っています。安全でない G-code は通さない安全ゲート付きです。

ESP32 の「Cheap Yellow Display」を使った無線の表示板で、礼拝中の演奏者に曲名とキーを見せます。ボード自体がウェブサーバーになっているので、Mac を使う人なら誰でもブラウザから更新できます。

04執筆と研究 Writing and research

ビザンチン障害耐性

ビザンチン障害耐性のもとで、複製された状態機械どうしがどう通信するかについての共著の研究論文です。UC Berkeley の RISE Lab で自分が立ち上げ、同級生を誘って進めたプロジェクトから生まれました。

検証こそがプロジェクト (README、英語)

もっともらしいAIの学びのプランを作るのは簡単でも、正しいプランを作るのはなぜ難しいのか。すべての主張を本文とひとつずつ照らし合わせる必要があり、それはデモでは見えない手順です。

「むずかしい」が一番やさしくなるとき (README、英語)

ひとつの誤答の集まりにつまみをひとつ付けるだけで、難易度設定が知らないうちに逆転してしまう仕組みと、それを防ぐ輪の設計について。
